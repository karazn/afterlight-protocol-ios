# Протокол: Свет

Офлайн 3D-игра для iPhone: восстановите питание трёх секторов заброшенной станции, собрав девять энергетических ядер, отбивайтесь импульсом от дронов и перезапустите центральный реактор.

## Управление

- левый стик / WASD — движение;
- правая половина экрана / мышь — свободная камера;
- «Импульс» / пробел — отбросить и временно отключить дронов;
- ядра подбираются автоматически;
- для финального запуска удерживайте позицию у реактора три секунды.

## Готовая iOS-часть

Xcode-проект находится в `ios/App/App.xcworkspace`. Идентификатор приложения: `com.afterlight.protocol`. Игра работает из локальных ресурсов Capacitor и не требует сети.

На Mac можно собрать неподписанный IPA одной командой из корня проекта:

```bash
chmod +x scripts/build-unsigned-ipa.sh
./scripts/build-unsigned-ipa.sh
```

Результат появится в `outputs/AfterlightProtocol-unsigned.ipa`. Неподписанный IPA нельзя установить штатным способом; для установки понадобится подпись или выбранный вами сторонний способ.

Альтернативно готовый workflow `.github/workflows/build-unsigned-ipa.yml` собирает тот же IPA на GitHub Actions `macos-15` и сохраняет его как artifact `AfterlightProtocol-unsigned-ipa`.
